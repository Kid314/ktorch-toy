# v5 整体设计说明

## 打包层与模型层分开

`pyproject.toml` 只描述如何安装Python包；模型、checkpoint、C++动态库仍然需要平台适配。把命令行和HTTP接口放在薄薄的入口层，底层继续复用经过小规模验证的Tensor和模型代码。

## HTTP边界

请求格式为：

```json
{"prompt":"我", "tokens":8}
```

响应为：

```json
{"text":"我……"}
```

服务在JSON边界校验请求大小、prompt类型、token数量，并把可预期的输入错误转成400。默认只监听回环地址，避免把教学服务意外暴露到局域网。

## 优化和生产化方向

真实服务需要独立处理认证/TLS、并发排队、取消、超时、背压、模型热加载、监控和资源隔离。推理计算还要接入v4的KV Cache，并验证缓存与重算的一致性。v5示例刻意保留这些缺口，防止一个几十行的http.server被误认为生产系统。

发布前需要在干净环境构建wheel，验证平台动态库、Python版本、checkpoint schema和命令入口。当前参考答案只做低负担导入与帮助检查。
