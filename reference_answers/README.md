本机验证采用小矩阵、小模型、短步骤，逐版串行执行；默认不执行长训练和大规模性能压测。详细结果在本目录的验证记录中据实填写。参考代码存在不代表主项目练习任务已经完成，也不自动代表生产环境验收通过。
